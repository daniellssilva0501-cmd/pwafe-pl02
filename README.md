# pwafe-pl02 · Ementa da cantina

Prática Laboratorial 02 de Programação Web Avançada para Front-End (ISTEC Porto).
Mostra a ementa do dia de uma cantina por categorias, com componentes React, props tipadas e listas.

## Como correr

```bash
npm install
npm run dev
```

## Estrutura das pastas

```
src/
├── components/   # Preco, Etiqueta, CartaoPrato, Seccao, ListaPratos, Alergenios
├── data/
│   └── pratos.ts # pratos da ementa
├── types.ts      # tipos Categoria e Prato
├── App.tsx
└── main.tsx
```
